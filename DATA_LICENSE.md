# Data License Scope

Status: public release policy.

This file defines the current data boundary.

It is not legal advice.

## License Direction

Malzu is intended to be public source-available, not permissive open source.

Target split:

- code: PolyForm Noncommercial 1.0.0
- curated graph data: CC BY-NC 4.0
- documentation: CC BY-NC 4.0
- upstream notices: preserved in `NOTICE.md`

Allowed project uses:

- individual learning
- independent research
- non-commercial community analysis
- classroom or academic use that is not commercialized
- public forks under compatible non-commercial terms
- reviewed community contributions

Blocked project uses:

- commercial threat-intelligence products
- paid SOC tooling
- vendor enrichment
- paid consulting deliverables
- SaaS wrapping
- private commercial forks
- resale of the dataset, UI, or derived commercial service

## Public Core

The public core dataset is intended to contain:

- source metadata
- source URLs
- malware family records
- normalized relationship records
- short curator-written claim summaries
- source-backed evidence references

The generated browser payload, `public/atlas.json`, is a projection of this public core.

It is generated by `scripts/build-atlas.mjs`.

It must not be hand-edited or committed.

The public core dataset must not contain:

- copied source prose
- copied diagrams
- copied screenshots
- copied tables
- copied logos
- copied IOC dumps
- copied YARA or Sigma rules
- malware samples
- payload downloads
- ransomware victim datasets
- ransom notes
- leak-site mirrors
- account-gated or private threat-intelligence exports
- Malpedia-derived public records

## Required Source Policy Fields

Every public source record must include:

- `license_posture`
- `redistribution_policy`
- `allowed_uses`
- `blocked_uses`
- `notice_required`

These fields are enforced by:

- `npm run validate`
- `npm run audit:licensing`

## Source Classes

`attribution_required`:

- allowed with required notice
- currently used for MITRE ATT&CK

`permissive_cc0_or_bsd_2_clause`:

- allowed with source license preserved
- currently used for MISP Galaxy

`standard_citation_notice`:

- usable as standard vocabulary or schema reference
- not evidence for malware relationships

`terms_limited_metadata_only`:

- metadata-only
- no sample download
- no sample upload
- no bulk mirroring

`us_government_public_domain_low_friction`:

- cite and summarize
- no logos, seals, or implied endorsement
- review third-party embedded material separately

`open_government_attribution_required`:

- cite and summarize with attribution
- avoid misleading reuse

`reuse_with_source_acknowledgement`:

- cite and summarize with source acknowledgement
- review embedded third-party material separately

`mixed_academic_citation_only`:

- metadata and short summaries only
- no copied figures, tables, or large excerpts without license review

`copyrighted_citation_only`:

- link and cite only
- curator-written summaries only
- no copied prose, diagrams, screenshots, tables, logos, IOC dumps, or detection rules

## Restricted Local Research

Restricted material is allowed only in ignored local paths.

Current restricted path:

- `data/research/restricted/`

Restricted material must not be used as direct public graph evidence.

Promotion workflow:

1. Find the original public report, advisory, standard, or paper.
2. Create a clean source record for that source.
3. Write original curator notes.
4. Cite only the clean source in `data/nodes` or `data/edges`.
5. Run validation and licensing audit.

## License Files

The public license files are:

- `LICENSE`: PolyForm Noncommercial 1.0.0 for code, plus project-level license summary
- `DATA_LICENSE.md`: CC BY-NC 4.0 policy for curated data and docs
- `NOTICE.md`: third-party notices and attribution

If these documents conflict, preserve the stricter non-commercial and source-safety boundary until the maintainer makes an explicit policy update.
